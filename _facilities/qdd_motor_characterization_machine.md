# QDD Motor Characterization Machine

![QDD motor characterization machine](/assets/img/facilities/qdd_motor_characterization_machine.jpg)

The QDD motor characterization machine is a customized setup for measuring and evaluating QDD motor performance. It can be used to collect data related to motor behavior, output, and performance under different operating conditions. This setup supports actuator and robot development by providing a dedicated characterization capability.

## Highlights

- Customized setup for QDD motor testing
- Supports motor performance characterization
- Useful for actuator and robot development workflows
