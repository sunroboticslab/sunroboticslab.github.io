# QDD 3 Segment Robot

![QDD 3 segment robot](/assets/img/facilities/qdd_3_segment_robot.jpg)

The QDD 3 segment robot is a robotic platform currently in development for studying QDD based actuation in a multi-segment robot. Once completed, the system will support experiments on modular actuation, robot motion, and control. This page can be updated as the system becomes available and the final capabilities are confirmed.

## Highlights

- QDD based multi-segment robotic platform
- Currently in development
- Intended for experiments on actuation, control, and robot behavior
