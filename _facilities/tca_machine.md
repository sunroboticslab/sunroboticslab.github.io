# TCA Machine

![TCA machine](/assets/img/facilities/tca_machine.jpg)

The TCA machine is a customized lab device used for work related to twisted and coiled artificial muscle actuators. It supports fabrication, testing, or characterization tasks depending on the experiment. This system helps the lab study actuator behavior and prepare samples for soft robotics research.

## Highlights

- Customized device for TCA related work
- Supports actuator preparation or characterization
