## Description

The Example Robot is a friendly placeholder robot used to demonstrate how a completed facility page entry should look. It is not an actual lab facility, but it shows the expected writing style: short, clear, and focused on what the system does. Its main capability is waving politely while reminding everyone to upload square images with clean file names.

## Highlights

- Demonstrates the preferred title, image, description, and highlight format.
- Shows how to write short facility descriptions without turning them into a full technical report.
- Provides a square image example using the matching file name `an_example_robot.jpg`.
- Can wave at the webpage visitor, which is not required but is emotionally appreciated.
